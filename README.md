# 🚗 CarStats Monitor (Android + ELM327 OBD-II)

Сучасний нативний Android-застосунок на **Kotlin** та **Jetpack Compose** для підключення до діагностичного Bluetooth-сканера **ELM327** і відображення параметрів автомобіля в режимі реального часу.

---

## 📱 Основні можливості

- **Цифровий кокпіт (Dashboard):**
  - Анімовані прилади спідометра (км/год) та тахометра (RPM).
  - Миттєва витрата палива (л/100км під час руху, л/год на холостому ходу).
  - Температура охолоджуючої рідини двигуна (°C) з колірною індикацією перегріву.
  - Навантаження на двигун (%) та положення дросельної заслінки (%).
  - Точна напруга бортової мережі / акумулятора (V).
- **Графіки в реальному часі (Real-time Graphs):**
  - Динамічні графіки зміни швидкості, обертів, температури та витрати палива.
- **Діагностика помилок (DTC / Check Engine):**
  - Зчитування кодів помилок з блоку керування (ЕБУ / ECU) через режим `Mode 03`.
  - Розшифровка популярних кодів українською мовою з рівнем критичності.
  - Скидання помилок та гасіння індикатора "Check Engine" через режим `Mode 04`.
- **Бортовий комп'ютер і журнал поїздок (Trip Logger):**
  - Запис поїздок (дистанція, витрачене паливо, середня витрата л/100км, тривалість).
  - Збереження в локальну базу даних **Room (SQLite)**.
  - Експорт та надсилання звітів про поїздки.

---

## 🛠 Технологічний стек

- **Мова:** Kotlin 2.0
- **UI:** Jetpack Compose + Material 3 (темна спортивна тема Cockpit)
- **Архітектура:** MVVM + Clean Architecture principles
- **Асинхронність:** Kotlin Coroutines & StateFlow
- **Зв'язок:** Android Bluetooth Classic (RFCOMM / SPP UUID `00001101-0000-1000-8000-00805F9B34FB`)
- **База даних:** Room Database (SQLite)
- **Сумісність:** Android 7.0 (API 24) — Android 15 (API 35)

## 🚀 Як відкрити та запустити проект

1. **Встановіть Android Studio:**
   - Якщо у вас є Windows Terminal / PowerShell:
     ```powershell
     winget install Google.AndroidStudio
     ```
   - Або завантажте з [офіційного сайту](https://developer.android.com/studio).

2. **Відкрийте проект:**
   - Запустіть Android Studio.
   - Виберіть **Open** -> вкажіть папку проекту:
     `d:\Programing\ProjectCarStatsMonitor`
   - Android Studio автоматично підтягне Gradle і завантажить усі залежності.

3. **Підключення до авто та адаптера:**
   - Вставте синій адаптер **ELM327 Mini** у діагностичний роз'єм OBD-II вашого автомобіля.
   - Увімкніть запалювання автомобіля (або запустіть двигун).
   - На телефоні перейдіть у звичайні налаштування **Bluetooth** та виконайте сполучення з пристроєм `OBDII` (пароль `1234` або `0000`).
   - Запустіть застосунок на телефоні, надайте дозвіл на Bluetooth і натисніть кнопку **"Підключити"** -> оберіть ваш адаптер зі списку!
